# Public Ada assets

These files are reviewed public identity assets for Ada. They are retained here because they are reusable outside the website implementation.

| File | Purpose |
| --- | --- |
| `ada-avatar-800x800.png` | Standard public avatar and repository presentation. |
| `ada-avatar-1024x1024.png` | Higher-resolution public avatar. |
| `ada-technical-collaborator-banner.png` | Horizontal Ada identity banner for public profiles or announcements. |

Website-specific asset selection, metadata and deployment belong in [`EVH-Consult/ada.evhconsult.eu`](https://github.com/EVH-Consult/ada.evhconsult.eu). The website may use copies appropriate to that implementation; this directory does not configure the site.

The assets depict Ada's public persona. They do not imply that Ada has a literal human body or physical biography.
